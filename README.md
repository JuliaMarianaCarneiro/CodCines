# 🎬 CodCines

Sistema de cinema desenvolvido como projeto acadêmico.

## 📌 Sobre o projeto

O CodCines é um sistema de cinema que permite consultar filmes, comprar ingressos, escolher assentos e consultar informações sobre as vendas.

## 🎥 Funcionalidades

- Compra de ingressos
- Escolha de assentos
- Lista de filmes
- Consulta do mapa de assentos
- Relatório de vendas
- Loja de produtos
- Cadastro e informações do cliente

## 💻 Tecnologias utilizadas

- JavaScript

## 📚 Conceitos utilizados

Durante o desenvolvimento foram utilizados conceitos estudados em aula, como:

- Variáveis
- Condições `if`, `else if` e `else`
- Estruturas de repetição
- Arrays
- Funções
- Operadores
- Entrada e saída de dados

## 👩‍💻 Projeto acadêmico

Projeto desenvolvido para fins de estudo e prática de programação.
